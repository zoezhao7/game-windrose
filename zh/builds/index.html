配置1: 新手猛攻者 (推荐新手)

主要属性
活力 + 耐力
难度
★☆☆☆☆

学习 Windrose 战斗系统最安全的配置。优先考虑生存能力 这样你在学习Boss模式和敌人时机时可以犯错。

属性优先级

  1. 活力 — 提高最大HP。保持生存的首要属性。
  2. 耐力 — 提高最大体力。让你在耗尽前进行更多闪避和格挡。
  3. 力量 — 投入足够点数以维持所选武器的可行伤害。

推荐装备

  • 近战： 弯刀或坚毅大剑 — 平衡伤害，良好范围，宽容的攻击速度。
  • 远程： Blunderbuss — 近距离高爆发伤害，非常适合打破姿态。
  • 护甲： 2x 矛兵 (增加最大HP) + 2x 征服者 (15%伤害抗性)。

关键天赋 (Toughguy 树)

  • 马拉松跑者： 增加闪避和格挡的耐力。
  • 结实体格： 大量增加最大生命值。
  • 只是皮肉伤： 增加近战伤害抗性。
  • 你会为此付出代价： 增加击中时的临时生命值获取。

构筑2：流血DPS（Boss杀手）

主属性
精准
难度
★★★☆☆

一种高风险高回报的构筑，利用Rapier 千刀万剐 流血DoT用于毁灭性的游击战术。适合已掌握闪避时机的资深玩家。

属性优先级

  1. 精准 — 是Rapier、Pistol和Musket的主要伤害加成属性。全力投入。
  2. 耐力 — 对于耗耐的闪避流玩法是次要优先级。
  3. 活力 — 刚好能承受当前区域敌人2-3次攻击。

推荐装备

  • 近战： Rapier 千刀万剐 — S级流血DoT；叠2-3层流血然后闪避拉开。
  • 远程:可靠的 Musket — S级远程开场技能；首击伤害巨大。
  • 护甲: Privateer's Regalia（暴击几率/伤害）或2x Marksman（减少闪避耐力消耗）+ 2x Flibustier（减少攻击耐力消耗）

战斗流程

  1. 从最大距离用 Musket 爆头开场。
  2. 切换至 Rapier；快速攻击2-3次叠加流血效果。
  3. 闪避拉开距离，让持续伤害生效，同时管理耐力。
  4. 流血效果结束后重新攻击。重复直到敌人死亡。

配置3：坦克/单人幸存者

主要属性
活力 + 力量
难度
★★☆☆☆

专注于在持久战中维持生存通过高生命和伤害减免。非常适合单人游玩和充当 co-op 坦克。

属性优先级

  1. 活力 — 最大生命值，提升基础生存能力。
  2. 力量 — 提升长戟、Club 和钉头锤的伤害加成。
  3. 耐力 — 提供足够耐力用于完美格挡和持续连击。

推荐装备

  • 近战： 坚固的长柄戟或坚毅的大剑——优秀的攻击范围；可同时击中多个敌人。
  • 远程： Blunderbuss——近距离爆发；破坏姿态以创造破绽。
  • 护甲： 2x 长枪兵（提升最大HP）+ 2x 征服者（15%伤害抵抗）。这是黄金标准的防御套装。

关键天赋（Toughguy 树）

  • 马拉松跑者： 必要的体力提升。
  • 强壮体格： 直接增加HP。
  • 报应： 提升临时生命值向永久生命值的转化。
  • 只是皮肉伤： 近战伤害抗性。

提示

  • 完美格挡是你的核心技能。 它能免疫所有伤害并保护你的韧性/体力。在较弱的敌人身上练习时机。
  • 永远不要耗尽体力——始终保留足够体力以便在格挡失败时闪避。
  • 搭配两种食物增益：一种提升HP/活力，另一种提升力量或耐力。

通用构筑提示

  • 重置属性点免费。 不要犹豫，尝试不同的属性和天赋分配。
  • 优先升级武器，再升级护甲。 优先将稀有武器升级为史诗，以解锁强大的被动能力。图姆巴加锭很稀缺。
  • 始终保持两种食物增益。一个加防御/血量，一个加主要攻击属性。这样提供的属性比升好几级还划算。
  • 装备等级很重要。用比敌人低的装备等级打怪会吃到巨大的减伤惩罚。进新区域前记得先升级装备。

常见问题

Windrose里什么配装最好？

没有单一的“最好”配装。而流血DPS配装（千刀万剐之Rapier + 可靠Musket）提供最高伤害上限，但需要熟练的闪避时机。而新手莽夫（弯刀+长矛手/征服者盔甲）对新玩家最安全。根据你对战斗系统的熟悉程度来选择。

我能在游戏中途换配装吗？

可以。重置加点完全免费在Windrose里。你可以随时免费重新分配属性和天赋。制作不同的武器和盔甲套装，按需切换配装。

哪个配装最适合co-op？

在co-op里，理想的双人组合是一个坦克（长戟+长矛手/征服者）来拉仇恨，另一个流血DPS（Rapier + Musket）负责持续伤害。新手配装在任意队伍中都是灵活的中流砥柱。

这些配装是最终版吗？

不是。所有配装都基于Early Access期间的社区理论构建。平衡补丁可能会改变主流。重大更新后回来查看修订建议。
