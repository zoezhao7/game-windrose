Windrose 服务器搭建与托管 — 专用服务器指南

用途
搭建联机服务器
资料类型
官方指南 + 清单
适用对象
团队玩家

Windrose 支持多人合作,而专用服务器搭建是搜索流量上极为重要的实用主题之一。本页将官方服务器搭建流程整理成简单的预启动清单,方便希望建立持久世界的玩家。

SteamCMD 安装命令

force_install_dir "C:\Game_Servers\Windrose_Server"
login anonymous
app_update 4129620 validate
quit

后续更新时,重新运行 app_update 4129620 validate 即可。每次补丁后请确保专用服务器版本与当前游戏客户端版本保持一致。

基础搭建流程

  1. 通过 SteamCMD 或 Steam 工具安装专用服务器包。
  2. 在服务器关闭状态下配置服务器名称、密码、区域、玩家人数与存档行为。
  3. 确保 UPnP 可用以支持 NAT 穿透,并在首次连接测试期间禁用代理或 VPN。
  4. 为 WindroseServer.exe 添加防火墙与杀毒软件白名单。
  5. 启动服务器,从另一台客户端测试连接,并在重大补丁前备份存档。

官方资料来源

如需获取确切的启动参数、配置字段与故障排查方法,请参阅官方 Windrose Dedicated Server Guide。本页是面向玩家的实用清单,每当官方指南更新时也应同步更新。

保存服务器 IP 与直连 IP

近期的连接性补丁新增了 保存服务器 IP 功能：使用有效的 IP 与端口连接成功后，客户端会将其保存在 多人游戏 → 已保存服务器 中。当 Steam 服务器浏览器不稳定，或服务器名与公开大厅冲突时，这是回到私人服务器最可靠的方式。直连 IP 同时绕开区域过滤，团队跨多个国家时尤其有用。

格式为 1.2.3.4:7777（默认游戏端口为 UDP 7777，除非 server.cfg 中另行指定）。首次连接成功后，服务器会自动出现在已保存服务器列表中。重装游戏前请备份本地 profile 配置文件以保留该列表。

自建服务器 vs. 付费托管

搭建 Windrose 服务器主要有三种现实方案，按团队规模与对在线时长的要求选择：

Windrose 服务器托管方案对比
方案适合优点缺点
游戏内 Listen 服务器2–3 位好友、同一晚零配置，Steam 好友邀请直接可用主机退出即关闭，无定时备份
自建专用服务器（本指南）4–8 人团队、有可常开的 PC免费，完全掌控备份与补丁时机需 Windows 主机 7×24 在线，自己处理防火墙与补丁
付费 Windrose 服务器托管对在线时长要求严格、或团队跨时区持续在线、自动备份、控制面板可一键重启月费（4–8 人位通常 10–25 美元/月）

如果选择付费托管，付款前请确认两件事：能否直接编辑 server.cfg（部分面板会覆盖该文件），以及是否提供可下载的存档备份。补丁破坏兼容性需要手动回滚时，这两点都是关键。

常见问题

如何搭建 Windrose 专用服务器？

安装 SteamCMD，将路径指向 C:\Game_Servers\Windrose_Server，运行 app_update 4129620 validate。在 server.cfg 中编辑服务器名称、密码与 MaxPlayers，然后启动 WindroseServer.exe。在 Windows 防火墙中放行该进程，并确认 UDP 7777 与 27015 已开放。详细步骤参见上方 SteamCMD 安装命令。

我可以自己搭建 Windrose 专用服务器吗？

可以。官方指南支持通过 SteamCMD 使用 app id 4129620 安装,并提供了当前的配置流程。

如何保存 Windrose 服务器 IP？

使用 ip:port 格式连接一次（例如 1.2.3.4:7777）。连接成功后，服务器会出现在 多人游戏 → 已保存服务器 列表中。该列表会在游戏重启后保留，是 Steam 服务器浏览器不稳定时回到私人专用服务器的最可靠方式。

自建服务器还是付费托管？

如果有可以 7×24 在线的 Windows 主机，自建服务器是免费的。付费托管（通常每月 10–25 美元，4–8 人位）适合需要严格在线时间或团队跨时区的玩家，提供稳定的运行时间和自动备份。两种方式的配置完全相同，只是运维层面不同。

专用服务器能在 Linux 上运行吗？

官方指南目前将其描述为仅支持 Windows,因此除非官方文档变更,否则请将 Linux 或无头部署视为不受支持。

需要备份服务器存档吗？

需要。请在打补丁前、更改难度或世界设置前、以及迁移主机前进行备份。
