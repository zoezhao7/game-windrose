Patch Notes v0.10.0.5.120 — Steam Cloud Saves Fix & Stability Update

May 04, 2026 · Patch Notes · By Bambino

Developer Kraken Express has released Patch v0.10.0.5.120 for Windrose, primarily addressing a critical issue with Steam Cloud Saves that was causing save corruption for some players.

What Changed

  • Steam Cloud Saves Fix — Resolved an issue where cloud saves could become corrupted during sync, potentially causing progress loss
  • Stability Improvements — General crash fixes and performance optimizations
  • Save System Hardening — Additional safeguards added to prevent future save-related issues

Guide Impact Analysis

This patch primarily affects the technical side of the game rather than gameplay mechanics. However, players who lost progress due to save corruption may need to revisit early-game content.

  • Server Guide: Dedicated server operators should update to this version. Check our Dedicated Server Guide for update instructions.
  • FAQ: We've updated our FAQ page with information about recovering from save corruption.
  • No recipe or balance changes — All crafting, resource, and boss data remains current.

Developer Note

Kraken Express stated they will be "closely monitoring feedback" after this update, suggesting further stability patches may follow quickly.
