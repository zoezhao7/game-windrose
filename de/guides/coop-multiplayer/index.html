Koop- & Mehrspieler-Leitfaden

Maximale Spieler
Bis zu 10
Empfohlen
2-4
Server-Typen
P2P + Dediziert

Windrose glänzt im Koop. Dieser Leitfaden behandelt, wie du Mehrspieler einrichtest, was du bei verschiedenen Gruppengrößen erwarten kannst und Strategien für effizientes Crew-Spiel.

1. Wie man Koop spielt

Wähle im Hauptmenü "Spiel hosten", um eine Session zu erstellen, oder "Spiel beitreten", um öffentliche Sessions zu durchsuchen. Du kannst auch Freunden direkt über Steam beitreten. Private Server erfordern ein vom Host festgelegtes Passwort.

2. Crew-Rollen

In einer idealen Crew von 4:

  • Kapitän (1) — Steuert das Schiff, verwaltet die Navigation, ruft Ziele während des Seekampfs aus.
  • Gunner (1-2) — Bedient Kanonen während Seeschlachten. Wechselt nach Bedarf zwischen Munitionstypen.
  • Späher/Sammler (1) — Erkundet voraus, sammelt Ressourcen, markiert Gefahren auf der Karte.
  • Enterer (1) — Spezialisiert auf Nahkampf zum Entern von Schiffen und Ausräumen von Dungeons.

3. Geteilter Fortschritt

Der Fortschritt ist an das Welt-Save gebunden, nicht an einzelne Charaktere. Alle Spieler teilen denselben Weltstatus, Quest-Fortschritt und dieselbe Basis. Charakter-Level und Talente sind jedoch pro Charakter. Das bedeutet, dass ein neuer Spieler, der einer Late-Game-Welt beitritt, unterleveled ist — er sollte POIs und Quests bestreiten, um aufzuholen.

4. Dedizierte Server

Für persistente Welten, die 24/7 laufen, richte einen dedizierten Server mit SteamCMD ein (App-ID: 4129620). Siehe unseren Leitfaden für dedizierte Server für die Schritt-für-Schritt-Einrichtung. Dedizierte Server verhindern Fortschrittsverlust, wenn der Host die Verbindung trennt.

Häufig gestellte Fragen

Kann ich Windrose solo spielen?

Ja. Das Spiel ist solo voll spielbar, obwohl einige Bosse und der Seekampf mit einer Crew deutlich einfacher sind.

Werden Gegenstände zwischen Welten übertragen?

Nein. Charaktere behalten ihr Level und ihre Talente, aber Inventar und Ausrüstung sind an jedes Welt-Save gebunden.
