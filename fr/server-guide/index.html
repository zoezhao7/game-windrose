Guide du serveur dédié Windrose

Intention
Héberger en coop
Type de source
Guide officiel + liste de contrôle
Idéal pour
Groupes

Windrose prend en charge le jeu coop, et l'hébergement dédié est l'un des sujets utilitaires les plus puissants pour le référencement. Cette page transforme la procédure officielle de configuration de serveur en une simple liste de contrôle avant lancement pour les joueurs qui souhaitent un monde persistant.

Liste de contrôle pour la configuration d'un serveur dédié Windrose
DomaineListe de contrôle
Pack serveurInstallez le serveur dédié Windrose via les outils Steam ou SteamCMD
App id SteamCMD4129620

Commandes d'installation SteamCMD

force_install_dir "C:\Game_Servers\Windrose_Server"
login anonymous
app_update 4129620 validate
quit

Pour mettre à jour plus tard, relancez app_update 4129620 validate. Veillez à maintenir la version du serveur dédié alignée sur celle du client de jeu après chaque patch.

Procédure de configuration de base

  1. Installez le pack serveur dédié via SteamCMD ou les outils Steam.
  2. Configurez le nom du serveur, le mot de passe, la région, le nombre de joueurs et le comportement de sauvegarde pendant que le serveur est arrêté.
  3. Vérifiez que l'UPnP est disponible pour le NAT punch-through, puis désactivez tout proxy ou VPN durant les premiers tests de connexion.
  4. Ajoutez des exceptions de pare-feu et d'antivirus pour WindroseServer.exe.
  5. Démarrez le serveur, testez la connexion depuis un client distinct et sauvegardez les fichiers avant les patchs majeurs.

Source officielle

Pour les arguments de lancement exacts, les champs de configuration et le dépannage, utilisez le guide officiel du serveur dédié Windrose. Cette page est une liste de contrôle conviviale et doit être mise à jour à chaque modification du guide officiel.

Questions fréquemment posées

Puis-je héberger un serveur dédié Windrose ?

Oui. Le guide officiel prend en charge l'installation via SteamCMD avec l'app id 4129620 et présente le flux de configuration actuel.

Le serveur dédié fonctionne-t-il sous Linux ?

Le guide officiel le décrit actuellement comme exclusif à Windows ; considérez donc les configurations Linux ou headless comme non prises en charge tant que la documentation officielle ne change pas.

Faut-il sauvegarder mon serveur ?

Oui. Sauvegardez avant les patchs, avant de modifier la difficulté ou les paramètres du monde, et avant toute migration d'hôte.
