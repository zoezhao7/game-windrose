Hébergement de serveur Windrose – Guide du serveur dédié

Intention
Héberger en coop

Windrose prend en charge le jeu coop, et l'hébergement dédié est l'un des sujets utilitaires les plus puissants pour le référencement. Cette page transforme la procédure officielle de configuration de serveur en une simple liste de contrôle avant lancement pour les joueurs qui souhaitent un monde persistant.

Commandes d'installation SteamCMD

force_install_dir "C:\Game_Servers\Windrose_Server"
login anonymous
app_update 4129620 validate
quit

Pour mettre à jour plus tard, relancez app_update 4129620 validate. Veillez à maintenir la version du serveur dédié alignée sur celle du client de jeu après chaque patch.

Procédure de configuration de base

  1. Installez le pack serveur dédié via SteamCMD ou les outils Steam.
  2. Configurez le nom du serveur, le mot de passe, la région, le nombre de joueurs et le comportement de sauvegarde pendant que le serveur est arrêté.
  3. Vérifiez que l'UPnP est disponible pour le NAT punch-through, puis désactivez tout proxy ou VPN durant les premiers tests de connexion.
  4. Ajoutez des exceptions de pare-feu et d'antivirus pour WindroseServer.exe.
  5. Démarrez le serveur, testez la connexion depuis un client distinct et sauvegardez les fichiers avant les patchs majeurs.

Source officielle

Pour les arguments de lancement exacts, les champs de configuration et le dépannage, utilisez le guide officiel du serveur dédié Windrose. Cette page est une liste de contrôle conviviale et doit être mise à jour à chaque modification du guide officiel.

Sauvegarder l'IP du serveur & connexion par IP directe

Les patchs de connectivité récents ont ajouté la fonction Sauvegarder l'IP du serveur : une fois connecté avec une IP et un port valides, le client la mémorise dans Multijoueur → Serveurs sauvegardés. C'est la manière la plus fiable de revenir sur un serveur privé lorsque le navigateur Steam est instable ou que le nom de votre serveur entre en collision avec des lobbies publics. La connexion par IP directe contourne aussi les filtres de région, pratique quand votre équipage est réparti dans plusieurs pays.

Format : 1.2.3.4:7777 (le port de jeu par défaut est UDP 7777, sauf si server.cfg le redéfinit). Après la première connexion réussie, le serveur apparaît dans Serveurs sauvegardés. Sauvegardez le fichier de profil local avant toute réinstallation pour conserver la liste.

Auto-hébergement vs. hébergement payant

Trois solutions réalistes pour héberger un serveur Windrose. Choisissez selon la taille de votre équipage et l'exigence d'uptime :

Comparaison des options d'hébergement Windrose
OptionAdapté àAvantagesInconvénients
Serveur d'écoute (in-game)2–3 amis, même soiréeAucune installation, invitations Steam fonctionnellesS'arrête quand l'hôte quitte, pas de sauvegardes planifiées
Dédié auto-hébergéÉquipage de 4–8 avec un PC toujours alluméGratuit, contrôle total des sauvegardes et du timing des patchsMachine Windows 24/7, gestion manuelle du pare-feu et des mises à jour
Hébergement payant WindroseÉquipages avec uptime strict ou fuseaux horaires différentsUptime continu, sauvegardes automatiques, panneau de contrôleAbonnement mensuel (typiquement 10–25 USD/mois pour 4–8 places)

Si vous choisissez un fournisseur payant, vérifiez deux points avant de payer : qu'il expose directement server.cfg (certains panneaux l'écrasent) et qu'il propose des sauvegardes téléchargeables. Les deux sont essentiels la première fois qu'un patch casse la compatibilité et qu'il faut faire un rollback manuel.

Questions fréquemment posées

Comment héberger un serveur dédié Windrose ?

Installez SteamCMD, pointez-le sur C:\Game_Servers\Windrose_Server et lancez app_update 4129620 validate. Modifiez server.cfg avec le nom du serveur, le mot de passe et MaxPlayers, puis lancez WindroseServer.exe. Autorisez le processus dans le pare-feu Windows et vérifiez que les ports UDP 7777 et 27015 sont ouverts.

Puis-je héberger un serveur dédié Windrose ?

Oui. Le guide officiel prend en charge l'installation via SteamCMD avec l'app id 4129620 et présente le flux de configuration actuel.

Comment sauvegarder une IP de serveur dans Windrose ?

Connectez-vous une fois au format ip:port (par exemple 1.2.3.4:7777). Après une connexion réussie, le serveur apparaît dans Multijoueur → Serveurs sauvegardés. La liste survit aux redémarrages du jeu et c'est le moyen le plus fiable de retourner sur un dédié privé quand le navigateur Steam est instable.

Auto-hébergement ou hébergement payant ?

L'auto-hébergement est gratuit si vous avez une machine Windows qui peut rester allumée. L'hébergement payant (typiquement 10–25 USD/mois) vaut le coût pour les équipages répartis sur plusieurs fuseaux horaires ou ceux qui ont besoin d'un uptime garanti et de sauvegardes automatiques. La configuration est identique ; seul l'aspect opérationnel diffère.

Le serveur dédié fonctionne-t-il sous Linux ?

Le guide officiel le décrit actuellement comme exclusif à Windows ; considérez donc les configurations Linux ou headless comme non prises en charge tant que la documentation officielle ne change pas.

Faut-il sauvegarder mon serveur ?

Oui. Sauvegardez avant les patchs, avant de modifier la difficulté ou les paramètres du monde, et avant toute migration d'hôte.
