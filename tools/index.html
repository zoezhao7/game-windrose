Frequently Asked Questions

Does Windrose Guides have interactive tools?

The current tools are static, crawlable planning pages. Interactive filters can be added later without changing the URLs.

Why add tools before more articles?

Tools attract repeated visits and earn links because they solve a player task faster than a long article.
