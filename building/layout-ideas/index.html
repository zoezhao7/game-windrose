Windrose Base Layout Ideas: Efficient Camp Designs (2026)

Here are community-tested base layout concepts for different stages of the game. Each design prioritizes efficient workflow, defense, and aesthetics.

Layout 1: The Starter Hub

Best for: First island, Days 1-3

  • Bonfire in center for light radius
  • Workbench adjacent to Bonfire (crafting proximity)
  • Cooking Fire next to Workbench (material sharing)
  • Tent at outer edge for Rested buff radius
  • 1-2 Storage Chests between Workbench and Cooking Fire

Layout 2: The Production Line

Best for: First permanent base, Days 4-10

  • Charcoal Kiln → Smelting Furnace in a line (material flow)
  • Workbench between furnace output and storage
  • Weaponsmith Workshop with dedicated roof (required!)
  • Armor Workshop under same roof structure
  • Storage area with labeled chests: Ore, Ingots, Weapons, Armor, Food

Layout 3: The Coastal Fortress

Best for: Mid-game permanent base

  • Dock extending into water for easy ship access
  • Perimeter wall/palisade for basic defense
  • Central courtyard with all crafting stations
  • Decorations in living quarters for max Rested buff
  • Ship moored at dock with onboard crafting backup

Layout 4: The Mobile Ship Base

Best for: Exploration-heavy playstyle

  • Workbench + Cooking Fire on main deck
  • Storage chests below deck
  • Bed in captain's quarters for Rested buff
  • Repair supplies easily accessible

FAQ

Should I build one big base or multiple small ones?

Early game: multiple small outposts near resources. Mid-game: one permanent centralized base with docks and defenses. Keep a small forward camp when exploring new biomes.

Can I move my buildings after placing them?

Yes, use Build Mode (B) to select and reposition structures. Some items may require deconstruction and rebuilding if materials are refunded.
