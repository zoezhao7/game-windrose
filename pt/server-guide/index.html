Windrose suporta jogo cooperativo, e a hospedagem dedicada é um dos tópicos utilitários mais fortes para busca. Esta página transforma o fluxo oficial de configuração do servidor em um simples checklist pré-lançamento para jogadores que desejam um mundo persistente.

Comandos de Instalação do SteamCMD

force_install_dir "C:\Game_Servers\Windrose_Server"
login anonymous
app_update 4129620 validate
quit

Para atualizar depois, execute novamente app_update 4129620 validate. Mantenha a versão do servidor dedicado correspondente à do cliente do jogo atual após os patches.

Fluxo Básico de Configuração

  1. Instale o pacote do servidor dedicado através do SteamCMD ou das ferramentas da Steam.
  2. Configure nome do servidor, senha, região, número de jogadores e comportamento de save enquanto o servidor estiver desligado.
  3. Certifique-se de que o UPnP está disponível para NAT punch-through, depois desabilite proxy ou VPN durante os primeiros testes de conexão.
  4. Adicione exceções de firewall e antivírus para WindroseServer.exe.
  5. Inicie o servidor, teste a conexão a partir de um cliente separado e faça backup dos saves antes de patches importantes.

Salvar IP do servidor & conexão por IP direto

Os patches recentes de conectividade adicionaram a função Salvar IP do servidor: depois que você conectar uma vez com um IP e porta válidos, o cliente memoriza em Multijogador → Servidores Salvos. É a forma mais confiável de voltar a um servidor privado quando o navegador da Steam está instável ou quando o nome do seu servidor colide com lobbies públicos. O IP direto também ignora os filtros de região, útil quando sua tripulação está espalhada por vários países.

Formato: 1.2.3.4:7777 (a porta de jogo padrão é UDP 7777, salvo se server.cfg sobrescrever). Após a primeira conexão bem-sucedida, o servidor aparece em Servidores Salvos. Faça backup do arquivo de perfil local antes de reinstalar para preservar a lista.

Auto-hospedagem vs. hospedagem paga

Há três formas realistas de hospedar um servidor Windrose. Escolha pelo tamanho da tripulação e nível de uptime exigido:

Comparação de opções de hospedagem Windrose
OpçãoIndicado paraVantagensDesvantagens
Listen server (no jogo)2–3 amigos, mesma noiteZero configuração, convites Steam funcionamCai quando o host sai, sem backups agendados
Dedicado auto-hospedadoTripulação de 4–8 com um PC sempre ligadoGrátis, controle total dos backups e do timing dos patchesMáquina Windows 24/7, firewall e patches manuais
Hospedagem paga WindroseTripulações com uptime rigoroso ou em fusos diferentesUptime contínuo, backups automáticos, painel de controleMensalidade (tipicamente 10–25 USD/mês para 4–8 vagas)

Se optar por um provedor pago, antes de pagar confirme dois pontos: que ele expõe o server.cfg diretamente (alguns painéis sobrescrevem) e que oferece backups de save baixáveis. Os dois importam na primeira vez que um patch quebrar a compatibilidade e for preciso fazer rollback manual.

Perguntas Frequentes

Como hospedo um servidor dedicado Windrose?

Instale o SteamCMD, aponte para C:\Game_Servers\Windrose_Server e execute app_update 4129620 validate. Edite o server.cfg com nome do servidor, senha e MaxPlayers, depois inicie WindroseServer.exe. Permita o processo no Windows Firewall e confirme que UDP 7777 e 27015 estão abertas.

Posso hospedar um servidor dedicado de Windrose?

Sim. O guia oficial suporta instalação via SteamCMD com app id 4129620 e descreve o fluxo de configuração atual.

Como salvo um IP de servidor no Windrose?

Conecte uma vez no formato ip:porta (por exemplo 1.2.3.4:7777). Após a conexão bem-sucedida, o servidor aparece em Multijogador → Servidores Salvos. A lista sobrevive a reinícios do jogo e é a forma mais confiável de voltar a um dedicado privado quando o navegador da Steam está instável.

Auto-hospedagem ou hospedagem paga?

A auto-hospedagem é gratuita se você tem uma máquina Windows que pode ficar ligada. A hospedagem paga (tipicamente 10–25 USD/mês) compensa para tripulações em fusos diferentes ou que precisam de uptime garantido e backups automáticos. A configuração é idêntica; só muda a parte operacional.

O servidor dedicado roda em Linux?

O guia oficial atualmente o descreve como exclusivo para Windows, então trate configurações em Linux ou headless como não suportadas a menos que a documentação oficial mude.

Devo fazer backup do save do servidor?

Sim. Faça backup antes de patches, antes de alterar dificuldade ou configurações de mundo, e antes de migrar hosts.
