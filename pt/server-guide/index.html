Windrose suporta jogo cooperativo, e a hospedagem dedicada é um dos tópicos utilitários mais fortes para busca. Esta página transforma o fluxo oficial de configuração do servidor em um simples checklist pré-lançamento para jogadores que desejam um mundo persistente.

Checklist de configuração de servidor dedicado Windrose
ÁreaChecklist
Pacote do servidorInstale o Windrose Dedicated Server através das ferramentas Steam ou SteamCMD
App id do SteamCMD4129620
Status do SOO guia oficial descreve atualmente o servidor dedicado como exclusivo para Windows
PortasAs portas são atribuídas dinamicamente via NAT punch-through; certifique-se de que o UPnP funciona e desabilite proxy/VPN durante os testes
Configurações do mundoDefina região, senha, número de jogadores, nome do servidor e comportamento de save antes de iniciar
FirewallPermita WindroseServer.exe no Windows Defender Firewall ou no firewall do host

Comandos de Instalação do SteamCMD

force_install_dir "C:\Game_Servers\Windrose_Server"
login anonymous
app_update 4129620 validate
quit

Para atualizar depois, execute novamente app_update 4129620 validate. Mantenha a versão do servidor dedicado correspondente à do cliente do jogo atual após os patches.

Fluxo Básico de Configuração

  1. Instale o pacote do servidor dedicado através do SteamCMD ou das ferramentas da Steam.
  2. Configure nome do servidor, senha, região, número de jogadores e comportamento de save enquanto o servidor estiver desligado.
  3. Certifique-se de que o UPnP está disponível para NAT punch-through, depois desabilite proxy ou VPN durante os primeiros testes de conexão.
  4. Adicione exceções de firewall e antivírus para WindroseServer.exe.
  5. Inicie o servidor, teste a conexão a partir de um cliente separado e faça backup dos saves antes de patches importantes.

Fonte Oficial

Para argumentos exatos de inicialização, campos de configuração e resolução de problemas, use o Guia Oficial de Servidor Dedicado Windrose. Esta página é um checklist amigável para o jogador e deve ser atualizada sempre que o guia oficial mudar.

Perguntas Frequentes

Posso hospedar um servidor dedicado de Windrose?

Sim. O guia oficial suporta instalação via SteamCMD com app id 4129620 e descreve o fluxo de configuração atual.

O servidor dedicado roda em Linux?

O guia oficial atualmente o descreve como exclusivo para Windows, então trate configurações em Linux ou headless como não suportadas a menos que a documentação oficial mude.

Devo fazer backup do save do servidor?

Sim. Faça backup antes de patches, antes de alterar dificuldade ou configurações de mundo, e antes de migrar hosts.
