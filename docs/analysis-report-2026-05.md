- 🟡 已有 Game8 等站的基础覆盖，需差异化竞争

## 四、🏆 最终推荐：2026年5月最适合做攻略站的3款游戏

---

### 🥇 第1名：Windrose（风起之旅）

```
推荐指数：⭐⭐⭐⭐⭐ (4.50/5.00)
最佳切入时机：现在！（EA刚发售1个月，攻略站真空期）
```

**核心理由：**

1. **蓝海市场**：目前几乎没有专属攻略站！搜索结果全是碎片化的单篇博客。Mobalytics 只有一篇配方，ProGameGuides 只有入门指南。这正是从零建立权威站的最佳窗口。

2. **首周100万销量**：参照 Valheim（首月500万）、Palworld（首月1500万）的轨迹，Windrose 有成为现象级的潜力。海盗题材 + Soulslite + 生存建造 = 差异化足够强。

3. **攻略需求量极大**：
   - 制作配方（至少50+种物品配方）
   - 资源地图（Clay / Copper / Iron / Gunpowder 位置）
   - Boss 攻略（Soulslite 战斗 = 玩家会大量搜索 Boss 打法）
   - 船舶系统指南
   - 基地建造教程

4. **Early Access**：意味着未来2-3年持续有内容更新，每次更新 = 新一轮搜索流量。

5. **定价优势**：预计 $20-30，门槛低于 $70 3A大作 = 更多玩家可触及。

**内容策略建议：**
- Week 1-2：全制作配方数据库 → 拦截「Windrose crafting」「Windrose recipes」搜索
- Week 3-4：资源位置地图 → 拦截「Windrose clay」「Windrose gunpowder」
- Month 2：Boss 攻略 + Build 指南
- Month 3：交互式地图（参照 heartopia.gg 的交互地图模式）

**域名建议：** `windrose.gg` / `windroseguides.com`

---

### 🥈 第2名：Crimson Desert（红色沙漠）

```
推荐指数：⭐⭐⭐⭐ (4.40/5.00)
最佳切入时机：稍晚但仍有机会（发售2个月，已有基础Wiki但远未完善）
```

**核心理由：**

1. **玩家基数巨大**：Steam 连续四周全球销量冠军，峰值125K+同时在线，129K+评价。这是2026年目前为止最成功的付费PC游戏。

2. **$69.99 = 高价值用户**：能花 $70 买游戏的玩家，更愿意花时间搜索攻略来提升游戏体验。这类用户的 Google Ads CPC 通常也更高（广告主愿意为高消费力用户出价）。

3. **内容深度 = SEO长尾**：
   - 3个角色 × 多种武器 × Abyss Core 系统 = 数百种 Build 组合
   - 开放世界收集要素（Sealed Abyss Artifacts）
   - 独特系统（扑克赌博攻略已被大量搜索）

4. **Pearl Abyss 长线运营**：《黑色沙漠》已运营10年+，Crimson Desert 同样会是长期更新的游戏。

5. **竞争可接受**：Game8 有基础 Wiki，但设计老旧、内容不全面。没有出现像 Fextralife / MapGenie 那样的头部第三方攻略站。

**内容策略建议：**
- Phase 1：所有 Build Guide（3角色 × 武器组合）→ 构筑"权威 Build 站"认知
- Phase 2：交互式地图（参照 Game8 但做得更好）
- Phase 3：全收集攻略 + Boss 攻略
- Phase 4：经济系统 / 赚钱攻略（韩国 MMO 玩家最爱）

**域名建议：** `crimsondesert.gg` / `crimsondesertbuilds.com`

### 🥉 第3名：Slay the Spire 2（杀戮尖塔2）

```
推荐指数：⭐⭐⭐⭐ (4.35/5.00)
最佳切入时机：现在！（EA阶段，元环境每月都在变 = 持续的内容需求）
```

**核心理由：**

1. **Roguelike 卡牌 = 攻略搜索之王**：这类游戏的玩家会反复搜索「best build」「tier list」「how to beat X」「card ranking」等关键词。搜索长尾极长。

2. **EA阶段 = 元环境快速迭代**：每次平衡补丁 = Tier List 更新 = 新一轮搜索流量。这种"持续刷新"的特性是攻略站梦寐以求的。

3. **5个角色 × 多流派 = 海量内容**：
   - Ironclad（力量 / 消耗）
   - Silent（毒 / 小刀 / Sly）
   - Defect（球 / 集中力）
   - Necrobinder（墓地 / 血魔法）
   - Regent（星辰 / 锻造 / Sovereign Blade）
   - + 4人 Co-Op 组合攻略

4. **社区极度活跃**：STS1 的 Reddit 社区至今仍在产出攻略内容。STS2 的攻略视频/文章传播性极强。

5. **没有 monopoly**：不像 Elden Ring 有 Fextralife、RE 有 residentevil.site。STS2 的攻略生态是碎片化的。

**竞争劣势：**
- SwitchbladeGaming、ProGameGuides 等通用游戏站已经入场
- 卡牌游戏的视觉呈现不如动作游戏吸引人
- 需要真正理解游戏深度才能写出好攻略（门槛较高）

**内容策略建议：**
- Tier List（角色排名 + 卡牌排名 + 遗物排名）× 每月更新
- 每个角色的深度 Build Guide
- Ascension 20 通关攻略
- Co-Op 最佳组合
- 数据分析（胜率、选牌率等，参照 STS1 的 Spirelogs）

**域名建议：** `slaythespire2.gg` / `sts2guides.com`

## 五、执行建议

### 5.1 推荐启动顺序

```
第一优先级：Windrose ← 立刻启动（蓝海窗口期可能只有2-3个月）
第二优先级：Slay the Spire 2 ← 同步启动（EA阶段持续有内容）
第三优先级：Crimson Desert ← 第2-3个月再启动（已有基础竞争）
```

### 5.2 如果只做一个站

**选 Windrose。** 理由简单：
- 竞争最少（几乎是空的）
- 玩家基数够大（首周100万+）
- EA阶段保证2-3年更新
- 海盗生存 = 欧美主流审美 = Google Ads 高 CPC
- 参照先例：Valheim 攻略站在2021年获得了海量流量

### 5.3 如果做两个站

**Windrose + Slay the Spire 2。** 互补：
- Windrose：动作/生存玩家 → 男性为主，18-35岁
- STS2：策略/卡牌玩家 → 偏硬核，25-40岁
- 两个站的内容策略完全不同，不会互相竞争

### 5.4 盈利预估

以 heartopia.gg 为参照（月访问量未披露，但 Discord 30万+ 的社区匹配度），Windrose 攻略站若能在 EA 第一年做到：
- 月PV 10万-50万（首年保守估计）
- Google Ads RPM $3-8（游戏类）
- 月收入预估：$300 - $4,000（首年）
- 长期：若 Windrose 成为 Valheim 级别（500万+销量），攻略站月收入可达 $5,000 - $20,000
