Windrose admite juego cooperativo, y el hosteo dedicado es uno de los temas de utilidad más fuertes para búsqueda. Esta página convierte el flujo oficial de configuración de servidor en una lista de verificación simple previa al lanzamiento para los jugadores que quieren un mundo persistente.

Comandos de Instalación de SteamCMD

force_install_dir "C:\Game_Servers\Windrose_Server"
login anonymous
app_update 4129620 validate
quit

Para actualizar más tarde, vuelve a ejecutar app_update 4129620 validate. Mantén la versión del servidor dedicado igual a la del cliente del juego después de cada parche.

Flujo de Configuración Básica

  1. Instala el paquete del servidor dedicado mediante SteamCMD o Steam tools.
  2. Configura el nombre del servidor, contraseña, región, número de jugadores y comportamiento de guardado mientras el servidor está apagado.
  3. Asegúrate de que UPnP esté disponible para NAT punch-through, luego desactiva proxy o VPN durante las primeras pruebas de conexión.
  4. Añade excepciones de firewall y antivirus para WindroseServer.exe.
  5. Inicia el servidor, prueba la conexión desde un cliente separado y haz copia de seguridad de los guardados antes de los grandes parches.

Guardar IP del servidor y conexión por IP directa

Los parches recientes de conectividad añadieron la función Guardar IP del servidor: una vez que te conectas con una IP y un puerto válidos, el cliente la recuerda en Multijugador → Servidores guardados. Es la forma más fiable de volver a entrar en un servidor privado cuando el navegador de Steam se vuelve inestable o el nombre de tu servidor choca con lobbies públicos. La IP directa también esquiva los filtros de región, útil cuando tu tripulación está repartida entre varios países.

Formato: 1.2.3.4:7777 (el puerto de juego por defecto es UDP 7777, salvo que server.cfg lo cambie). Tras la primera conexión exitosa, el servidor aparece bajo Servidores guardados. Haz copia del archivo de perfil local antes de reinstalar para conservar la lista.

Auto-hospedaje vs. hosting de servidor de pago

Hay tres formas realistas de hospedar un servidor de Windrose. Elige según tamaño de la tripulación y exigencia de uptime:

Comparación de opciones de hosting para Windrose
OpciónMejor paraVentajasDesventajas
Servidor escucha (en el juego)2–3 amigos, una misma nocheCero configuración, las invitaciones de Steam funcionanMuere cuando el host sale, sin copias programadas
Dedicado auto-hospedadoTripulación de 4–8 con un PC siempre encendidoGratis, control total sobre copias y momento de los parchesNecesita una máquina Windows 24/7 y mantener firewall y parches manualmente
Hosting de servidor de pagoTripulaciones con uptime estricto o en distintas zonas horariasUptime continuo, copias automáticas, panel de controlCuota mensual (típicamente 10–25 USD/mes para 4–8 plazas)

Si optas por un proveedor de pago, antes de pagar confirma dos cosas: que dé acceso directo al server.cfg (algunos paneles lo sobrescriben) y que ofrezca copias de guardado descargables. Ambas cosas son críticas la primera vez que un parche rompe la compatibilidad y necesitas hacer un rollback manual.

Preguntas Frecuentes

¿Puedo hostear un servidor dedicado de Windrose?

Sí. La guía oficial admite la instalación con SteamCMD con app id 4129620 y ofrece el flujo de configuración actual.

¿Cómo monto un servidor dedicado de Windrose?

Instala SteamCMD, apúntalo a C:\Game_Servers\Windrose_Server y ejecuta app_update 4129620 validate. Edita server.cfg con el nombre del servidor, contraseña y MaxPlayers, luego lanza WindroseServer.exe. Permite el proceso en el cortafuegos de Windows y verifica que UDP 7777 y 27015 estén abiertos.

¿Cómo guardo una IP de servidor en Windrose?

Conéctate una vez usando el formato ip:puerto (por ejemplo 1.2.3.4:7777). Tras una conexión correcta, el servidor aparece en Multijugador → Servidores guardados. La lista sobrevive a reinicios del juego y es la manera más fiable de volver a un dedicado privado cuando el navegador de Steam falla.

¿Auto-hospedaje o hosting de pago?

El auto-hospedaje es gratis si tienes un PC con Windows que pueda quedarse encendido. El hosting de pago (típicamente 10–25 USD/mes) compensa para tripulaciones en distintas zonas horarias o que necesiten uptime garantizado y copias automáticas. La configuración es idéntica; sólo cambia la parte operativa.

¿El servidor dedicado funciona en Linux?

La guía oficial actualmente lo describe como exclusivo para Windows, así que trata las configuraciones para Linux o sin interfaz como no soportadas a menos que la documentación oficial cambie.

¿Debería hacer copia de seguridad de mi guardado de servidor?

Sí. Haz copia de seguridad antes de los parches, antes de cambiar la dificultad o la configuración del mundo y antes de migrar de host.
