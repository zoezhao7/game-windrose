Guía de Servidor Dedicado de Windrose

Intención
Hostear cooperativo
Tipo de Fuente
Guía oficial + lista de verificación

Grupos

Windrose admite juego cooperativo, y el hosteo dedicado es uno de los temas de utilidad más fuertes para búsqueda. Esta página convierte el flujo oficial de configuración de servidor en una lista de verificación simple previa al lanzamiento para los jugadores que quieren un mundo persistente.

Lista de verificación de configuración de servidor dedicado de Windrose
ÁreaLista de Verificación
Paquete del servidorInstala el Windrose Dedicated Server mediante Steam tools o SteamCMD
App id de SteamCMD4129620
Estado del SOLa guía oficial actualmente describe el servidor dedicado como exclusivo para Windows
PuertosLos puertos se asignan dinámicamente mediante NAT punch-through; asegúrate de que UPnP funcione y desactiva proxy/VPN durante las pruebas
Configuración del mundoEstablece región, contraseña, número de jugadores, nombre del servidor y comportamiento de guardado antes del lanzamiento

Comandos de Instalación de SteamCMD

force_install_dir "C:\Game_Servers\Windrose_Server"
login anonymous
app_update 4129620 validate
quit

Para actualizar más tarde, vuelve a ejecutar app_update 4129620 validate. Mantén la versión del servidor dedicado igual a la del cliente del juego después de cada parche.

Flujo de Configuración Básica

  1. Instala el paquete del servidor dedicado mediante SteamCMD o Steam tools.
  2. Configura el nombre del servidor, contraseña, región, número de jugadores y comportamiento de guardado mientras el servidor está apagado.
  3. Asegúrate de que UPnP esté disponible para NAT punch-through, luego desactiva proxy o VPN durante las primeras pruebas de conexión.
  4. Añade excepciones de firewall y antivirus para WindroseServer.exe.
  5. Inicia el servidor, prueba la conexión desde un cliente separado y haz copia de seguridad de los guardados antes de los grandes parches.

Fuente Oficial

Para los argumentos exactos de lanzamiento, los campos de configuración y la solución de problemas, usa la Guía oficial de Windrose Dedicated Server. Esta página es una lista de verificación amigable para el jugador y debe actualizarse siempre que cambie la guía oficial.

Preguntas Frecuentes

¿Puedo hostear un servidor dedicado de Windrose?

Sí. La guía oficial admite la instalación con SteamCMD con app id 4129620 y ofrece el flujo de configuración actual.

¿El servidor dedicado funciona en Linux?

La guía oficial actualmente lo describe como exclusivo para Windows, así que trata las configuraciones para Linux o sin interfaz como no soportadas a menos que la documentación oficial cambie.

¿Debería hacer copia de seguridad de mi guardado de servidor?

Sí. Haz copia de seguridad antes de los parches, antes de cambiar la dificultad o la configuración del mundo y antes de migrar de host.
